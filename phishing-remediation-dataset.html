Try it locally

  1. Download the 10K preview as demo.jsonl.
  2. Download inspect_preview.py into the same folder.
  3. Run this command with Python 3. It uses the standard library, makes no API calls, checks fields and unique IDs, and exports the same records to a CSV you can inspect or import.
python inspect_preview.py --dataset phishing_remediation_reports --file demo.jsonl --csv demo-cases.csv

The printed summary shows the loaded count, fields, subject_line counts, and first record. This is a format and inspection example, not a model benchmark. Free-preview use remains subject to its existing non-commercial license.

Quality evidence and limits

Both tiers scored 94/100 in the project's automated audit on 13 October 2026. The paired verification found zero exact record or ID overlap between the free and paid tiers. Similarity checks are bounded. The score is an internal record-quality measure.

The records contain incident narratives and containment actions, not full email bodies, EML files, benign/phishing labels, live threat feeds, or executable tool-call trajectories. They do not establish phishing-detector accuracy.
