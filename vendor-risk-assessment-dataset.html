Try it locally

  1. Download the 10K preview as demo.jsonl.
  2. Download inspect_preview.py into the same folder.
  3. Run this command with Python 3. It uses the standard library, makes no API calls, checks fields and unique IDs, and exports the same records to a CSV you can inspect or import.
python inspect_preview.py --dataset third_party_vendor_risks --file demo.jsonl --csv demo-cases.csv

The printed summary shows the loaded count, fields, findings_risk_score counts, and first record. This is a format and inspection example, not a model benchmark. Free-preview use remains subject to its existing non-commercial license.

  • Unencrypted backups
  • Legacy TLS endpoints
  • Critical exposed vulnerability
  • Missing privileged MFA
  • Out-of-region backup retention
  • Prior exposure with incomplete corrective evidence

More rows provide additional synthetic variants, not 100,000 independent real-world cases or additional workflow families.

Quality evidence and limits

Both tiers scored 94/100 in the project's automated audit on 13 October 2026. The paired verification found zero exact record or ID overlap between the free and paid tiers. Similarity checks are bounded. The score is an internal record-quality measure.

The current records contain High and Critical findings; Low, Medium, and benign cases are not included. This is not a balanced risk-classification dataset. Ratings are configured labels, not calibrated breach probabilities. Records are not authentic SOC 2 reports, compliance certifications, or a complete vendor-control database. They do not establish GRC-model accuracy.

Read the public quality audit. Inspect fit before buying. No independent train/test benchmark or real-world transfer result is provided.
